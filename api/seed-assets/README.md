# Local demo illustrations

These original schematic illustrations were composed for CampusFix with the already installed Lucide icons. They are explicitly marked as fictional demo illustrations and are not photographs or evidence of real campus incidents.

Regenerate with `node web/scripts/create-demo-assets.mjs` from the repository root. The additive seeder converts these trusted local SVG assets to WebP; the public upload API still rejects SVG uploads.

Lucide icons use the ISC license; its full notice is retained in LUCIDE-LICENSE.txt. Existing project-generated fountain/computer images remain unchanged.
